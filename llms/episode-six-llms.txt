# Episode Six

> Episode Six is a global payment technology company founded in 2015 that supplies banks,
> fintechs and brands with a cloud-native card issuing and ledger management platform
> marketed as TRITIUM. The platform is an API-first architecture offering real-time RESTful
> API processing for credit, debit, prepaid, commercial, installment and virtual card
> programs, plus a parallel ledger covering virtual accounts, revolving credit, installments,
> loans, interest-bearing and term deposits, multi-currency and negative balance accounts.
> Episode Six operates in 45+ countries with employees in 20 countries.

Generated by the API Evangelist enrichment pipeline on 2026-08-12. Episode Six publishes no

  documentation and APIs." Contact-sales form; access codes are issued by Episode Six.

## APIs

- Episode Six TRITIUM Platform API: Real-time RESTful card issuing, issuer processing and
  ledger management. NO PUBLIC OPENAPI. NO PUBLIC BASE URL. NO PUBLIC AUTHENTICATION
  REFERENCE. An agent cannot call this API from public information alone.
- [Episode Six Documentation MCP Server](https://docs.episodesix.com/mcp): A Model Context
  Protocol server over the TRITIUM documentation. Auth-gated — an unauthenticated JSON-RPC
  `tools/list` returns HTTP 401 `invalid_token`. Scope: `mcp:search` (documentation search
  only; grants no access to the payments platform).
